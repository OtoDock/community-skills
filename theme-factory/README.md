# Theme Factory

**Agent Skill package** — instruction/reference content only, no server, no
code execution. Installs the `theme-factory` skill
([Agent Skills](https://agentskills.io) format), which agents load on demand
when a task matches its description.

A curated set of ten professional themes — each a cohesive color palette with matched font pairings — that an agent can apply to anything it produces: slide decks, documents, reports, HTML landing pages. Includes a showcase PDF so you can preview every theme, and instructions for generating a brand-new theme on the fly when none of the presets fit.

Pairs well with OtoDock's document tools (PowerPoint/Word/PDF authoring) and interactive artifacts.

## Contents

One skill, loaded `on_demand`:

| Skill | Description |
|---|---|
| `theme-factory` | Toolkit for styling artifacts with a professional theme: 10 pre-set color/font themes plus on-the-fly theme generation. Use when styling slides, docs, reports, or HTML pages and a cohesive look is wanted. |
